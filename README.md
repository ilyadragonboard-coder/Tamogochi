# 🐱 Kotik Tamagotchi

Мини-тамагочи с котиком на **Python + Tkinter**. Кормите, играйте, укладывайте спать и лечите своего питомца — иначе он заболеет и может умереть.

## Возможности

- 4 характеристики питомца: **сытость**, **настроение**, **энергия**, **здоровье**
- Автоматическое ухудшение показателей со временем (тик каждые 3 секунды)
- Случайный риск заболеть при низких показателях
- Питомец может **заболеть** и **умереть**, если за ним не следить
- Простая анимация состояний: сердечки, "Zzz" во сне, реакция на еду и т.д.
- Управление через 4 кнопки: **Кормить**, **Играть**, **Спать**, **Лечить**

## Требования

- Python 3.8+
- Tkinter (обычно идёт в комплекте с Python; на Linux может понадобиться `sudo apt install python3-tk`)

Внешних зависимостей нет — используется только стандартная библиотека.

## Установка и запуск

```bash
git clone https://github.com/<your-username>/Tamogochii.git
cd Tamogochii
python main.py
```

Убедитесь, что PNG-файлы котика лежат в той же папке, что и `main.py` — иначе вместо картинки появится заглушка с сообщением об отсутствующем файле.

## Как играть

- **Кормить** — повышает сытость и немного настроение
- **Играть** — сильно повышает настроение, но тратит энергию и сытость
- **Спать** — переключает режим сна; во сне энергия восстанавливается
- **Лечить** — снимает болезнь и немного восстанавливает здоровье

Если сытость или настроение падают до нуля, а также при болезни — здоровье снижается. Когда здоровье достигает нуля, питомец умирает, и все действия блокируются.
